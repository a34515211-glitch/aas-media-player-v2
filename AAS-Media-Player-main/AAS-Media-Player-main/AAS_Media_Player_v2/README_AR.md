# AAS Media Player v2 — مشروع Android

هذه نسخة مصدرية جديدة مبنية على Kotlin وAndroidX Media3، وليست ملف APK جاهزاً.

## ما تم تضمينه في هذه المرحلة
- مشغل Android أصلي باستخدام Media3 ExoPlayer.
- اختيار ملفات الصوت والفيديو من منتقي ملفات Android، مع حفظ إذن قراءة URI الذي يمنحه النظام.
- خدمة MediaSessionService لدعم جلسة تشغيل الوسائط في الخلفية والتحكم النظامي.
- واجهة فيديو مع إخفاء عناصر التحكم بعد 5 ثوانٍ.
- النقر المزدوج على النصف الأيمن للتقديم والأيسر للتراجع.
- تحكم منفصل في PlaybackParameters للسرعة وطبقة الصوت.
- حفظ آخر ملف وموضع تشغيله محلياً.
- مؤقت نوم أساسي.
- سير عمل GitHub Actions لبناء APK تجريبي تلقائياً.

## ميزات لم تكتمل بعد — لا تعتبرها موجودة
- مكتبة تفهرس كل ملفات الجهاز تلقائياً؛ اختيار الملفات يتم بموافقة المستخدم عبر منتقي Android.
- قوائم تشغيل وإدارة مكتبة دائمة كاملة.
- قص الصوت/الفيديو وتصديره.
- كشف التكرارات بمقارنة SHA-256 ونقلها إلى سلة مهملات قابلة للاسترجاع.
- خمس طبقات صوتية محسوبة DSP مستقلة عن السرعة على جميع الأجهزة والصيغ؛ القيم الحالية تستخدم Media3 PlaybackParameters وقد تختلف نتائجها حسب الجهاز والترميز.
- ترتيب حلقات واتساب الذكي مع شاشة مراجعة.
- إعدادات لغة وثيم متكاملة ورمز حماية آمن.
- شاشة تحديث داخل التطبيق لتثبيت APK موقع والتحقق من التوقيع.
- اختبارات فعلية على أجهزة متعددة.

## بناء APK من هاتفك عبر GitHub
1. أنشئ مستودعاً جديداً في GitHub باسم `AAS-Media-Player`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، مع إبقاء مجلد `.github/workflows`.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build AAS Media Player APK** ثم **Run workflow**.
5. بعد نجاح البناء افتح تشغيل المهمة الناجح، ثم نزّل Artifact باسم `AAS-Media-Player-debug-apk`.
6. فك ضغط الملف لتحصل على `app-debug.apk`، ثم ثبّته على هاتفك. قد يطلب Android السماح بالتثبيت من المتصفح أو مدير الملفات.

## تنبيه
هذه نسخة تطويرية أولى من المشروع الأصلي الجديد. يجب اختبارها على هاتف Android فعلي قبل اعتبارها إصداراً للبيع أو الاستخدام النهائي. APK الناتج Debug وليس إصدار متجر موقّعاً بمفتاح نشر.
